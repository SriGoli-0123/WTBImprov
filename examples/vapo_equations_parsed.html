VAPO Equations & Math Formulations

Fully Rendered Mathematics of Vagueness-Aware Preference Optimization

1. WTB Dialogue MDP Formalization

We model a multi-turn dialogue as a graph-conditioned Markov Decision Process $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \lambda)$:

  • State Space $\mathcal{S}$: At step $t$, the state is $s_t = (H_t, \mathcal{Z}_t)$, where $H_t$ is the conversation transcript history and $\mathcal{Z}_t \subseteq V$ is the active frontier of topological execution graph $G = (V, E)$.
  • Action Space $\mathcal{A}$: The rollout action contains CoT reasoning tokens $c_t$ and execution tokens $f_t$.

The transition probability $\mathcal{P}(s_{t+1} \mid s_t, a_t)$ moves the topological frontier forward when tool calls match adjacent nodes, or triggers terminal failure $s_{\text{fail}}$ if formatting/parameters deviate.

2. State-Conditional Entropy Guidance

To compute the token-level average entropy $E(c_i)$ of Chain-of-Thought reasoning tokens $c_i$ in rollout $o_i$:

$$E(c_i) = -\frac{1}{W} \sum_{j=1}^{W} \sum_{w \in V} P(w \mid H_t, c_{i,

The **Context Ambiguity Index** $D(H_t)$ dictates the entropy direction. Under **Epistemic Tool Uncertainty**, it is computed as the normalized entropy of tool choice:

$$D_{\text{uns}}(H_t) = -\frac{1}{\log N} \sum_{k=1}^N p(t_k \mid H_t) \log p(t_k \mid H_t)$$

Under **Supervised Gating**, the head $D_\psi(H_t)$ is trained on ground-truth graph indicators $y_t = \mathbb{I}(\text{ask\_user} \in \mathcal{Z}_t)$:

$$D_\psi(H_t) = \sigma(W_\psi h_t + b_\psi)$$
$$\mathcal{L}_{\text{amb}}(\psi) = -\mathbb{E}_{(H_t, y_t)} \left[ y_t \log D_\psi(H_t) + (1-y_t) \log(1 - D_\psi(H_t)) \right]$$

Using $D(H_t)$, the adaptive entropy scaler $\gamma(H_t)$ shifts the policy advantage $\tilde{A}_{t,i}$:

$$\gamma(H_t) = \alpha \cdot (D(H_t) - \tau)$$
$$\tilde{A}_{t,i} = A_{t,i} + \text{clip}\left( \gamma(H_t) E(c_i), -\frac{|A_{t,i}|}{\varsigma}, \frac{|A_{t,i}|}{\varsigma} \right)$$
Exploration Mode ($D(H_t) > \tau \implies \gamma(H_t) > 0$): Policy receives a positive reward for high entropy, encouraging the model to ask clarifying questions.
Execution Mode ($D(H_t) < \tau \implies \gamma(H_t) < 0$): Policy receives an entropy penalty, forcing the model to make direct, concise tool calls.
3. Step-wise State-Matching Rewards (SSMR)

The step-wise dense reward $r_t$ provides credit assignment based on node matching progress:

$$r_t(s_t, a_t) = \Delta_{\text{progress}} \cdot R_{\text{node}} - \eta - \mu \cdot \mathbb{I}(\text{Redundant Call}) - R_{\text{fail}} \cdot \mathbb{I}(s_{t+1} = s_{\text{fail}})$$

We then calculate the standard GRPO advantage $A_{t,i}$ relative to the group of rollouts using the discounted future rewards $R(o_{i, t}) = \sum_{k=t}^{T_i} \lambda^{k-t} r_k$:

$$A_{t,i} = \frac{R(o_{i, t}) - \text{mean}_j(R(o_{j, t}))}{\text{std}_j(R(o_{j, t}))}$$
4. Decoupled Value-Grading (DVG)

To prevent formatting failures from corrupting reasoning parameters, we split the objective into reasoning loss (on CoT index set $\mathcal{I}_{\text{reason}}$) and action loss (on tool call index set $\mathcal{I}_{\text{action}}$):

Reasoning Objective:

$$\mathcal{J}_{\text{reason}}(\theta) = \mathbb{E} \left[ \frac{1}{S} \sum_{i=1}^S \sum_{k \in \mathcal{I}_{\text{reason}}} \min \left( r_{i,k}(\theta)\tilde{A}_{t,i}, \text{clip}(r_{i,k}(\theta), 1-\epsilon, 1+\epsilon)\tilde{A}_{t,i} \right) \right]$$

Action Objective:

$$\mathcal{J}_{\text{action}}(\theta) = \mathbb{E} \left[ \frac{1}{S} \sum_{i=1}^S \sum_{k \in \mathcal{I}_{\text{action}}} \min \left( r_{i,k}(\theta)A_{t,i}, \text{clip}(r_{i,k}(\theta), 1-\epsilon, 1+\epsilon)A_{t,i} \right) \right]$$
