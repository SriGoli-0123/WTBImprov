WildToolBench Evaluation Mechanics

WildToolBench measures model ability over entire multi-turn trajectories using two key metrics. Most models fail due to self-conditioning biases in conversational loops.

Optimal Path (OP)
Evaluates if the agent chose the shortest topological path in the action DAG.
Accomplish Progress (AP)
Measures what fraction of the target tasks were successfully resolved.
